1. Visão Geral do Módulo

O módulo de Lembretes é o núcleo da experiência do aplicativo Lembri. Ele permite que o usuário crie lembretes de rotina ou medicamentos rapidamente em seu smartphone, visualize o status de conexão com relógios Wear OS, envie os lembretes para o pulso e acompanhe confirmações de conclusão em tempo real.

2. Telas e Fluxos no Expo Router

Rota Expo Arquivo Responsabilidade
/(tabs) MobileAPP/src/app/(tabs)/index.tsx Painel principal: status de conexão com o relógio, formulário de adição rápida e lista recente de lembretes enviados
/(tabs)/lembretes MobileAPP/src/app/(tabs)/lembretes.tsx Histórico completo, filtros por status (todos, pendentes, concluídos) e agendamento

3. Gerenciamento de Estado no Zustand

O estado do módulo é controlado de forma centralizada e imutável pela store useLembretesStore:

interface LembretesState {
  lembretes: Lembrete[];
  filtro: 'todos' | 'pendentes' | 'concluidos';
  isLoading: boolean;
  erro: string | null;

  adicionarLembrete: (titulo: string, horario?: string) => Lembrete;
  toggleConcluido: (id: string) => void;
  removerLembrete: (id: string) => void;
  definirFiltro: (filtro: 'todos' | 'pendentes' | 'concluidos') => void;
  sincronizarComRelogio: (id: string, concluidoNoRelogio: boolean) => void;
  resetarParaMocks: () => void;
}

4. Catálogo de Componentes e Tokens Visuais

  • ThemedText: Variantes title, subheading, label, small e button;
  • Card: Superfície branca com bordas arredondadas (Radius.lg = 16) e borda sutil;
  • TouchTarget: Alvo mínimo de toque padronizado em 56dp;
  • Colors: Contraste acessível em preto, branco e tons de cinza funcionais.

5. Massa de Dados Mockados e Fixtures

Localizada em MobileAPP/src/mocks/lembretes.mock.ts, a fixture inicial provê dados pré-populados para testes no emulador, com itens pendentes e concluídos em diferentes horários do dia.

6. Acessibilidade Mobile (WCAG 2.2 AAA)

  • Contraste aprimorado mínimo de 7:1 para texto normal e 4.5:1 para texto grande (1.4.6);
  • Todos os botões contam com área de toque mínima de 56dp (TouchTarget, superando o mínimo de 44x44dp AAA);
  • Botões com ícones utilizam accessibilityRole="button" e accessibilityLabel autônomo e contextual (2.4.9);
  • Ações de exclusão contam com mecanismo de reversão (*Undo* de 5-10s) ou confirmação explícita (3.3.6);
  • Sem limite de tempo inflexível nos fluxos (2.2.3);
  • Conclusão indicada por texto explicativo ("Concluído no relógio ✓" / "Pendente") além de cor;
  • Compatibilidade integral com TalkBack e VoiceOver.

7. Sincronização com Relógio Wear OS

A sincronização é bidirecional via modules/wear-connector:

  • Celular → Relógio: Mensagem na rota /lembrete com payload contendo { id, titulo, horario };
  • Relógio → Celular: Mensagem na rota /confirmacao com payload { id, concluido: true }, disparando atualização imediata na store Zustand.
